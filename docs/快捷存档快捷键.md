# 快捷存档快捷键

## 功能概述

快捷存档允许玩家在游戏运行过程中按下系统级全局快捷键，立即创建一份当前存档备份。主窗口处于后台、最小化到托盘、游戏使用无边框全屏或常见独占全屏时，快捷键仍可由 Windows 分发给 GameSave Manager。

默认快捷键为：`Ctrl+Shift+F5`。

## 使用条件

- 游戏必须通过 GameSave Manager 启动。
- 应用仍在监测该游戏的运行进程。
- 游戏必须已经配置有效的存档目录，目录中至少存在一个可备份文件。
- GameSave Manager 必须保持运行；隐藏到托盘不会影响快捷键。

外部直接启动的游戏、未配置进程监测的 Steam 游戏，以及已经退出监测状态的游戏不会响应快捷存档。

## 设置快捷键

1. 打开左侧导航栏中的「设置」。
2. 找到「快捷存档」卡片。
3. 使用开关启用或关闭快捷键。
4. 点击「重新录制」，按住 `Ctrl`、`Alt` 或 `Shift`，再按一个主键。
5. 页面显示“已注册”后，新快捷键立即生效。

支持的主键：

- 字母 `A-Z`
- 数字 `0-9`
- 功能键 `F1-F11`

不支持 Windows 键组合、`F12`、`PrintScreen` 和无修饰普通按键，以减少系统保留键及误触问题。点击「恢复默认」可恢复 `Ctrl+Shift+F5`。

## 存档结果

快捷存档使用热备份流程，先复制运行中的存档文件到临时快照，再生成 `.tar` 归档。存档名称格式为：

```text
快捷存档 yyyy-MM-dd HH-mm-ss
```

归档文件仍遵循项目统一格式：

```text
{Unix时间戳}_快捷存档 yyyy-MM-dd HH-mm-ss.tar
```

本地归档创建完成后会立即发送系统通知。若游戏配置了云端存储，云端上传继续在后台执行，不阻塞本地成功通知。

## 全屏兼容说明

快捷键通过 Win32 `RegisterHotKey` 注册，并由独立隐藏消息窗口接收 `WM_HOTKEY`，不依赖 GameSave Manager 窗口焦点，也不使用可能引起反作弊软件关注的低级键盘钩子。

如果组合已被游戏、系统或其他软件注册，设置页会提示“快捷键已被占用”，原有快捷键继续有效。此时请重新录制其他组合。

Windows 的专注助手、勿扰模式或游戏模式可能暂时隐藏通知横幅，但不会影响存档文件的创建；通知仍按系统策略处理。

## 常见提示

| 提示 | 含义 |
|------|------|
| 快捷存档成功 | 本地 `.tar` 文件已经创建完成 |
| 暂无可快捷存档的游戏 | 当前没有通过应用启动并处于监测状态的游戏 |
| 快捷存档进行中 | 上一次快捷存档尚未结束，本次重复按键未创建新任务 |
| 快捷存档失败 | 存档目录为空、文件读取失败或工作目录写入失败 |
| 快捷键已被占用 | 该组合已经由其他程序或系统注册，需要更换 |
